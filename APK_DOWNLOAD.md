# Android APK Download

This folder contains the latest debug and release APKs for your app. You can download them directly to your phone using the following links:

- [Debug APK](./android/app/build/outputs/apk/debug/app-debug.apk)
- [Release APK (signed & aligned)](./android/app/build/outputs/apk/release/app-release-signed-aligned.apk)

To install:
1. Download the APK to your device.
2. Open the file and follow the prompts to install (enable "Install from unknown sources" if needed).

If you need a public link, consider uploading to a service like Google Drive, Dropbox, or GitHub Releases for remote access.
